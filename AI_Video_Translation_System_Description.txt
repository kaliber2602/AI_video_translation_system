* Dịch nội dung.
* Tạo subtitle.
* Text-to-Speech.
* Voice Cloning.

* Tìm kiếm semantic.

# 86. FINAL ARCHITECTURAL PRINCIPLE

Hệ thống được chia thành:

```text
┌────────────────────────────────────────────┐
│          USER PROCESSING LAYER             │
│                                            │
│ Upload → STT → Translate → TTS → Video   │
│                                            │
│ USER QUOTA / STORAGE / CREDITS            │
└─────────────────────┬──────────────────────┘
                      │
                      ▼
┌────────────────────────────────────────────┐
│       PLATFORM INTELLIGENCE LAYER          │
│                                            │
│ Transcript → Embedding → Vector Search    │
│                    ↓                       │
│                   RAG → LLM                │
│                    ↓                       │
│ Search / QA / Summary / Chapters          │
│                                            │
│        NO USER AI CREDIT DEDUCTION         │
└────────────────────────────────────────────┘
```

Nguyên tắc:

> **User quota được dùng để giới hạn các tài nguyên processing, storage và các tính năng tiêu thụ trực tiếp tài nguyên có thể quy đổi thành consumption của người dùng.**

> **RAG, Semantic Search, Embedding và LLM Intelligence là năng lực cốt lõi của nền tảng và không khấu trừ AI credits của người dùng.**

> **Tuy không tính quota, toàn bộ system-level usage vẫn phải được tracking, monitoring và audit để kiểm soát chi phí, hiệu năng, capacity và bảo mật.**
